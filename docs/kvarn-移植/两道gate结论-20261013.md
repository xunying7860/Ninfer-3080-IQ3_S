# 阶段 1 两道 gate 的结论（2026-10-13 晚，全部本机 docker 实跑，sm_86/RTX 3080）

## gate 1 · 旋转等价性 → 结论：照搬 ninfer 侧，不补 cross-slice 蝶形
- 结构层 **PASS（逐位相同）**：把 beellama 蝶形配单点精确 `2^-4` 后与 ninfer `normalized_hadamard_d256_inplace` 三组共 **3,145,728 元素 max|Δ| = 0**。
- 逐字层 **FAIL**（1 PASS + 2 FAIL）：gauss `4.768372e-07`（PASS）/ outlier `1.220703e-04` / bound `3.814697e-06`；三组平均 cosine 都是 `1.000000000000000`。绝对差大的两组按其 |out|（≤1068、≤48）归一后是 2.4e-07 / 4.8e-07 ⇒ 纯 float 舍入，不是算法差异。
- 自逆误差：A 侧 3.06e-07/2.40e-07/4.77e-07，B 侧 2.52e-07/1.30e-07/1.16e-07（归一）⇒ 都正交到 float 极限，**ninfer 侧更准**。
- 配对层 = **恒等映射** `map[j]=j`：256 个单位向量探测非恒等 0/256、负号 0/256，残差 3.725290e-09；反证：slice 顺序对调后 max|Δ| = 9.80 / 2.135e03 / 32.0。
- 差异根因闭环：beellama 常量 `0.08838834764831845f × 0.7071067811865475f = 0.062499997860716139`，与精确 1/16 差 **3.423e-08（0.57 ulp）**，且施加在最后一级蝶形之前；double 域复刻两条路径的相对差恰为该值（三组相同）。D512（slices=4）同样一致（5.09e-07）。
- 三方印证：`oracle/make_tiles.rotate_d256` 与 beellama 逐字路径 **bit 全同 0/2048**，与 ninfer max|Δ| = 2.384186e-07。
- **代价判定**：照搬 ninfer = 零额外代码、归一化精确；照搬 beellama = 多 2 次乘 + 主动引入 1.7e-08 常量误差、且要新增 cross-slice 蝶形，无收益。差异比实测量化噪声小约 5 个数量级（gate 2：合成 maxd|s_col| 7.486e-03、真实 3.338e-06）。

## gate 2 · CUDA 量化/存储 kernel 与标量 oracle 对拍 → 结论：oracle 可作算法基准，不能作逐字节基准
- 结构层 **PASS**：`iters=0`（纯布局+算术）**576/576 record、0 差异字节**，覆盖 2/3/4/5/6-bit × {高斯/离群/真实}；存储路径（旋转 + F16 stage）**0/131072 字节**。
- 任意配置逐字节 **FAIL**：`iters=16` 默认 flags 193/576 record、48,747 字节（真实数据只占 8 字节，合成占全部）；换成上游真实 flag `-use_fast_math` 后连 `iters=0` 都 371/576 record、1,017 字节 ⇒ **标量 oracle 物理上无法充当上游 GPU 构建的逐字节基准**。
- 归因：Sinkhorn 是病态轨迹（真实数据 `best_iter=0` 稳定，合成 `best_iter≈13-16` 放大到 maxd|s_col| 7.5e-3 ≈ 1e4 倍）；旁证 —— 1-ulp 输入扰动造成 4,600 字节 vs host-vs-device 4,532 字节，同量级。
- **验收口径改为**：`iters=0` 比字节 + `iters=16` 比 `maxd|s_col|` 与解码 cosine（不再要求任意配置逐字节相等）。
- smem 实测：required **69,704 B（68.07 KB）**，设备 opt-in 上限 **101,376 B（99.00 KB）**，余 31,672 B；smem/SM 102,400 B ⇒ **1 block/SM**（128 线程、30 寄存器/线程）。

## 对档位与路线的直接影响
1. 旋转不用改：ninfer 现有 `hadamard_d256.cuh` 直接可用 ⇒ 省掉 doc 03 §3.9 那条"必须实现 cross-slice"的工作量（doc 该处结论需更正）。
2. 量化 kernel 的字节布局已验通 ⇒ 阶段 2-3 可以直接进引擎接线（按默认口径：K4V4 主攻、基线 `11327e96`、几何 P1）。
3. 质量口径沿用阶段 0 实测：K4V4_g128 与生产打平（−0.090%/+0.224%）、K4V2_g128 超判据 25-29 倍 ⇒ 别把 K4V2 当上线档。

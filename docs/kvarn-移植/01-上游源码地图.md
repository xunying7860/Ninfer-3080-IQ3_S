### `make_layout` 摘录（压缩改写，非逐字）（[cpp:634](https://github.com/Anbeeld/beellama.cpp/blob/main/src/llama-kvarn.cpp#L634)）

> 真实源码带 4 条 `assert`、一语句一行、结尾 `return layout;`；**逐字原文见 `..\参考-beellama核对.md` §3.1**。

```c
llama_kvarn_tile_layout llama_kvarn_make_layout(int head_dim, int group, int key_bits, int value_bits) {
    size_t off = 0;
    layout.k_payload_off = off;
    layout.k_payload_bytes = llama_kvarn_packed_bytes(head_dim * group, key_bits);
    off += layout.k_payload_bytes;
    layout.k_s_col_off = off;  off += size_t(head_dim) * sizeof(uint16_t);
    layout.k_zp_off    = off;  off += size_t(head_dim) * sizeof(uint16_t);
    layout.k_s_row_off = off;  off += size_t(group)    * sizeof(uint16_t);
    layout.v_payload_off = off;
    layout.v_payload_bytes = llama_kvarn_packed_bytes(group * head_dim, value_bits);
    off += layout.v_payload_bytes;
    layout.v_s_col_off = off;  off += size_t(head_dim) * sizeof(uint16_t);
    layout.v_s_row_off = off;  off += size_t(group)    * sizeof(uint16_t);
    layout.v_zp_off    = off;  off += size_t(group)    * sizeof(uint16_t);
    layout.tile_bytes = llama_kvarn_align_up(off, 8);
}
```

### `geometry_for` 原文（[cpp:690](https://github.com/Anbeeld/beellama.cpp/blob/main/src/llama-kvarn.cpp#L690)）

```c
case 64:  geometry = { KVAR_N_GROUP,  64,  64, 1 }; return true;
case 128: geometry = { KVAR_N_GROUP, 128, 128, 1 }; return true;

```

### smem 精确分解

```
KVAR_N_SHARED_FLOATS = 16384 + 8×128 + 2 + 16 = 17,426 floats = 69,704 B = 68.1 KB
```

| 段 | floats | 字节 |
|---|---:|---:|
| tile (128×128) | 16,384 | 65,536 |
| log_s_col / log_s_row | 256 | 1,024 |
| s_col / s_row | 256 | 1,024 |
| best_col / best_row | 256 | 1,024 |
| col_std / row_std | 256 | 1,024 |
| best_imbalance / better | 2 | 8 |
| reduce (4×4) | 16 | 64 |
| **合计** | **17,426** | **69,704** |

**sm_86 的 `smpbo` ≈ 99 KB → 68.1 KB 直接装得下，余 30.9 KB。** 只需 `cudaFuncSetAttribute` 开动态 smem opt-in。

**实测占用率（GATE2 §5）**：required 69,704 B、opt-in 上限 101,376 B（余 31,672 B）、静态 smem 0、寄存器 30/线程 ⇒ **1 block/SM**（smem/SM 仅 102,400 B，**不能并发 2 block**；128 线程/SM，上限 1536）。

lowshmem 变体只要 **3.1 KB**（不缓存 tile，每次重读 global），靠 `GGML_KVARN_TEST_FORCE_LOWSHMEM` 环境变量可强制测试（[kvarn.cu:2260](https://github.com/Anbeeld/beellama.cpp/blob/main/ggml/src/ggml-cuda/kvarn.cu#L2260) 附近）。

`non_swa_tail_groups = 2` 的理由（源码注释原文）：

> `llama_kvarn_can_remove_range` promises a position-independent suffix rollback that reaches back into **the previous group** … With a single slot both groups alias one stage row range, so re-sealing a partially reopened group sources its surviving prefix from the newer group's rows. **Two slots keep the reopened group's own F16 source resident.**

且明确不影响质量：

> Perplexity is unchanged between depth 1 and 2 (7.1898 either way, Qwen3.6-27B kvarn6 at 4K).

`tail_policy_for` 关键行：

```c
const uint32_t intrinsic = std::min(group_size, effective_window);   // = 128
const uint32_t effective_tokens = std::max(intrinsic, explicit_tokens);
```

**intrinsic 128 是硬下限**，请求 0 也保留。
